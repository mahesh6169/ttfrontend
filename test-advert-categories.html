Key Findings

  • ISSUE: The pricing section is being shown for "Real Estate > Room > Wanted" combination
  • The form correctly has logic to skip pricing for wanted ads (line 367-370 in AdvertForm.jsx)
  • However, the validation logic might still be expecting pricing data
  • The issue appears to be specific to the way the form is handling state updates when switching ad types

Root Cause Analysis

The problem is likely in the form state management:

  1. User selects "Real Estate" → "Room" → pricing section appears (correct for offered)
  2. User switches to "Wanted" → pricing section should disappear but validation might still expect it
  3. The form sections are being recalculated when adType changes (line 80), but there might be stale pricing data

Recommended Fix

When switching to "wanted" ad type, ensure:

  1. Clear any existing pricing data from formData
  2. Reset selectedPriceType state
  3. Ensure validation skips pricing for wanted ads
